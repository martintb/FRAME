# frame-twin

Latent diffusion model for generating material structure ensembles.

## Purpose

`frame-twin` implements the materials digital twin using a conditioned denoising diffusion probabilistic model (DDPM) with an internal variational autoencoder (VAE). It learns the distribution of material structures from parametric cartoons and generates diverse, physically plausible structural ensembles.

## Features

- **Latent diffusion model**: DDPM operating in compressed latent space
- **Variational autoencoder**: Compresses high-dimensional voxel grids for efficient generation
- **Conditional generation**: Guide structure generation with experimental constraints
- **Training pipeline**: Tools for training on voxelized cartoon data
- **Inference & sampling**: Generate structural ensembles from the trained model
- **Model management**: Save, load, and version trained models

## Architecture

- **Encoder**: VAE encoder compresses 128³ × N-channel voxel grids to latent space
- **Diffusion model**: DDPM learns to denoise in latent space
- **Decoder**: VAE decoder reconstructs voxel grids from latent representations
- **Conditioning**: Optional experimental data integration

## Workflow

1. **Training**: Learn from voxelized cartoons generated by `frame-geo`
2. **Inference**: Sample latent codes and denoise to generate structures
3. **Validation**: Check physical plausibility of generated structures
4. **Ensemble generation**: Produce multiple diverse structures for analysis

## Design Principles

- **PyTorch-native**: Built entirely on PyTorch for GPU acceleration
- **Memory-efficient**: Latent space reduces computational cost
- **Reproducible**: Control random seeds for deterministic generation

## Usage

```python
# Example (API under development)
from frame_twin import LatentDiffusionModel

# Train a model
model = LatentDiffusionModel(...)
model.train(training_data)

# Generate structures
ensemble = model.sample(n_samples=100)
```
